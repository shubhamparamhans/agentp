# Archive Guide

Archived documentation stays in the repository for traceability, but it is no longer the active source of truth.

## Folders

- `legacy-root-docs/` contains older top-level implementation notes and one-off documents.
- `legacy-feature-docs/` contains feature-doc migration artifacts, old summary indexes, and retired feature-folder formats.
- `project-history/` contains historical project snapshots such as release notes or one-time correction summaries.

## Rule

If a document is useful for history but confusing in the active docs flow, move it here instead of deleting it.
