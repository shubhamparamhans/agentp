# Open Questions

Use this page to track decisions that block roadmap or implementation planning.

## Current Questions

- Should UDV remain primarily read-only, or should editing become a first-class product track?
- Which data sources beyond PostgreSQL and MongoDB are strategic for the next release window?

- Which features are production-ready enough to be called out in an external-facing release note?

## How To Use This File

- Keep each question short and decision-oriented.
- Link the owning feature folder when a question belongs to a specific implementation.
- Move resolved items into the relevant feature or architecture document once the decision is made.
