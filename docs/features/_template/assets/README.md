# Assets

Use this folder for supporting material that should be preserved but should not replace the main feature docs.

## Good Fits

- prompt responses and planning notes
- background analysis
- screenshots and diagrams
- sample requests or responses
- imported legacy markdown files
- research notes and comparisons

## Rule

If a file here becomes essential to understanding current scope or implementation, summarize it in:

- `index.md`
- `prd.md`
- `design.md`
- `status.md`

Keep `assets/` for preservation and reference, not as the only place where important decisions live.
